## 새 도감과 생물 설명

### 조간대 (tidal_habitat)

밀물 때 잠기고 썰물 때 드러나는 바닷가예요.

- 게임 역할: 세 번째 서식지가 열려요. 물 교환과 빛을 조절할 수 있어요.
- 과학 설명: 조간대에서는 조석에 따라 침수 시간, 온도와 염분 등이 달라집니다. 이 모형은 물 교환과 빛의 효과만 다룹니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 세포 부착 (cell_adhesion)

세포가 서로 붙어서 모여 있을 수 있는 성질이에요.

- 게임 역할: 세포의 역할 분화로 이어지는 조합 재료예요.
- 과학 설명: 세포 접착에는 세포 표면 단백질과 세포 밖 물질 등이 관여합니다. 붙어 있는 군체가 모두 복잡한 다세포 생물인 것은 아닙니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 세포의 역할 분화 (division_of_labor)

한 몸 안의 세포가 서로 다른 일을 맡는 거예요.

- 게임 역할: 다세포 조류와 해면형 여과자를 탐색하는 재료예요.
- 과학 설명: 다세포성은 여러 생물 계통에서 독립적으로 진화했습니다. 세포 간 협력과 분화의 정도도 계통마다 다릅니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 다세포 조류 (macroalgae)

여러 세포가 몸을 이루며 빛으로 양분을 만드는 생물이에요.

- 게임 역할: 조간대의 영양분을 쓰고 산소를 공급해요. 그늘에서는 생산이 줄어요.
- 과학 설명: 많은 다세포 조류는 광합성으로 유기물을 만듭니다. 큰 조류의 몸은 다른 생물의 서식 공간이 될 수 있습니다. 조류는 하나의 단일한 진화 계통을 뜻하지 않습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 여과 섭식 (filter_flow)

물속의 작은 먹이를 걸러 먹는 방법이에요.

- 게임 역할: 해면형 여과자를 발견하는 조합 재료예요.
- 과학 설명: 여과 섭식자는 물의 흐름과 포획 구조를 이용합니다. 여과 대상과 입자 크기는 종에 따라 다릅니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 해면형 여과자 (sponge)

몸속으로 물을 흘려 작은 먹이를 걸러 먹는 동물 모형이에요.

- 게임 역할: 기존 광합성 미생물을 먹어요. 먹이가 줄면 번식도 줄어요.
- 과학 설명: 실제 해면동물은 편모가 있는 세포로 물의 흐름을 만들고 세균 등 작은 입자를 포획합니다. 일부 종은 광합성 공생 미생물을 품습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 신경망 (nerve_net)

신호를 주고받는 신경세포가 그물처럼 이어진 구조예요.

- 게임 역할: 자포동물형 포식자를 탐색하는 재료예요.
- 과학 설명: 자포동물의 신경계는 감각과 운동을 조절합니다. 분산된 신경망과 더 집중된 구조가 함께 나타나기도 합니다. 이것을 모든 동물 신경계의 직접 조상으로 단정할 수는 없습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 자포동물형 포식자 (cnidarian)

촉수로 작은 먹이를 잡는 동물 모형이에요.

- 게임 역할: 기존 초식 원생생물을 먹어요. 먹이가 많을 때 성장하고 산소가 부족하면 줄어요.
- 과학 설명: 자포동물은 자포세포로 먹이를 포획하거나 방어합니다. 실제 먹이는 종과 크기에 따라 달라집니다. 여기서는 작은 원생생물을 먹는 하나의 기능형으로 표현했습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 조류의 은신처 (nursery)

조류 사이의 작은 틈이 먹잇감의 숨을 곳이 돼요.

- 게임 역할: 조간대 조류가 5 이상이면 초식 원생생물의 포식 손실이 40% 줄어요.
- 과학 설명: 서식 공간의 복잡성은 포식자의 접근과 먹이의 피난 가능성을 바꿉니다. 조류가 언제나 모든 먹이 생물을 보호하는 것은 아닙니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 연결된 얕은 바다 (resilient_web)

생산과 섭식, 분해가 함께 이어진 생태계예요.

- 게임 역할: 두 관찰을 조합하면 두 번째 장을 마쳐요. 조건을 바꾸며 계속 실험할 수 있어요.
- 과학 설명: 먹이망은 물질과 에너지의 이동을 연결합니다. 에너지는 흐르며 일부가 열로 빠져나가고, 영양 물질은 여러 경로로 순환합니다. 짧은 공존은 장기 안정성을 보장하지 않습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 빛과 생산의 차이 (light_comparison)

빛을 바꾸자 같은 생태계의 생산량이 달라졌어요.

- 게임 역할: 밝음과 그늘에서 각각 측정해 발견해요. 기원 데이터 2를 한 번 받아요.
- 과학 설명: 광합성은 빛뿐 아니라 영양분, 온도 등 여러 요인의 영향을 받습니다. 같은 개체군의 조건을 비교해야 빛의 효과를 더 잘 구분할 수 있습니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.

### 이어지는 먹이망 (living_web)

오래전 발견한 미생물과 새 동물이 서로 영향을 줬어요.

- 게임 역할: 실제 여과·포식·분해가 일어난 조간대를 기록해요. 기원 데이터 2를 한 번 받아요.
- 과학 설명: 생산자가 만든 유기물은 섭식과 사망을 거쳐 이동합니다. 분해자는 유기물에서 영양분을 되돌려 놓습니다. 이 모형은 각 기능을 소수의 개체군으로 대표합니다.
- 단순화: 조합은 진화의 실제 순서나 직접 조상 관계를 뜻하지 않는 탐색 모형입니다. 수치와 시간, 종 사이의 관계를 교육용으로 단순화했습니다.
