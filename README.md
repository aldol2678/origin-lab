# Origin Lab | 기원의 실험실

An experimental evolution and ecosystem sandbox web game.

**Status:** Early prototype / Work in progress

## v0.3 · 살아 있는 실험실

생명을 발견하고 생태계를 만든 뒤, 같은 시작 상태를 두 개 복사해 한 조건만 바꿔 비교하는 독립 웹게임입니다. 기존 두 장의 콘텐츠 **조합 34개·발견 42개·생물 9종·서식지 3개**를 유지합니다.

## 실행

`origin-lab-v0.3.html`을 최신 브라우저에서 여세요. 게임에 설치·계정·외부 서비스가 필요하지 않습니다. 코드와 스타일, 기본 화면은 단일 HTML에 들어 있으며 외부 네트워크 요청은 없습니다.

파일 열기를 제한하는 환경에서는 다음 명령 후 `http://localhost:8000/origin-lab-v0.3.html`을 여세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

로컬 검증 환경의 관리 정책이 `file://`를 차단하여 직접 파일 열기 검증은 BLOCKED입니다. 로컬 HTTP와 네트워크 차단 상태의 HTML 실행은 PASS입니다. 실제 휴대폰·사람 직접 플레이는 UNKNOWN입니다. GitHub CI의 일반 Chromium 결과는 QA 보고서에 별도로 기록합니다.

## 플레이와 변경 사항

- **세계**: 생물 배치, 영양분 공급, 생태계 관찰. 첫 기본 생산 생물을 배치하면 무료 배양 보조기가 열립니다. 생산 생물이 살아 있으면 최대 에너지 +8/초를 추가 수확하며 진화 탭에서 켜고 끌 수 있습니다. 수동 탐침도 유지합니다.
- **실험실**: 두 재료를 무료로 조합합니다. 기존 34개 조합과 과학 설명을 보존했습니다.
- **진화 → 같은 시작, 다른 조건**: 빛, 은신처, 분해자 중 질문을 고릅니다. 30/60/120/180초의 생태계를 실제 엔진으로 빠르게 계산합니다. 비교 중 본 세계는 일시 정지합니다.
- **연구용 표본 준비**: 발견한 생물과 자원을 두 군에 똑같이 준비한 뒤 조건을 나눕니다. 본 세계에 재화를 주거나 생물을 배치하지 않습니다. 차이가 작을 때 유용합니다.
- **그래프**: 산소, 서식지별 영양분·유기물·종별 개체 수·포식 손실·분해 환원·생태계 생산을 실제 계산값으로 표시합니다. A는 실선, B는 점선이며 수치 표와 JSON 내보내기도 제공합니다.
- **기록 → 연구 노트**: 조건·시드·표본 준비·기간·측정 요약을 최대 20건 보관합니다. 삭제할 수 있고 재화나 도감 보상은 없습니다.

분해자 실험은 첫 장에서 분해 미생물을 발견하면 열립니다. 빛과 은신처 실험은 두 번째 장의 조간대와 해당 생물이 필요합니다. 실험 해금에 별도 에너지 비용은 없습니다. 첫 장 엔딩·‘여기서 마치기’·두 번째 장 바로 진입·기존 일회성 환생 보상을 유지합니다.

## 저장 이전과 복구

v0.3은 **스키마 4 / `originLab.save.v4`**만 씁니다. v0.2의 v3 정본은 원본과 저장 이력을 백업한 뒤 읽기 전용으로 이전합니다. v1/v2도 직접 이전할 수 있습니다. v3가 있으면 오래된 v1/v2 기록으로 돌아가지 않습니다.

- 두 탭의 충돌이나 서로 갈라진 저장 이력은 자동 점수 비교·병합 없이 멈추고 복구 선택을 요청합니다.
- **백업·복구**에서 기록을 비교하고 확인 후 선택합니다. 가져오기/복구 전에 현재 상태와 이력을 백업합니다.
- 연구 노트도 JSON 내보내기/가져오기·백업에 포함됩니다. 손상된 v4 필드를 임의로 빈 노트로 바꾸지 않습니다.
- 구판 HTML을 다시 열어도 v4 정본은 바뀌지 않습니다. 다만 브라우저·주소·파일 경로에 따라 저장 영역이 다를 수 있으므로 자동 승계를 보장하지 않습니다. 다른 저장 영역에서는 기존 게임의 JSON 내보내기 → v0.3 가져오기를 사용하세요.
- 자동 저장은 주요 행동 및 10초마다 수행합니다. 강제 종료 직전 미저장 변화까지 보장하지 않습니다.

## 개발 및 검증

Node.js 24, npm, Playwright Chromium을 사용합니다. 게임 자체에는 Node.js가 필요하지 않습니다.

```sh
npm ci
npx playwright install chromium
npm run build
npm test
npm run test:browser
```

설치된 Chromium을 쓰려면 `CHROMIUM_PATH`를 지정하세요. `npm run test:balance`는 탐침 호출과 완료 시간 비교를 재생합니다. `npm run audit:public`은 Git에 등록한 공개 파일의 경로·텍스트를 검사합니다.

- `src/game.js`, `src/chapter.js`: 기존 엔진·두 장 콘텐츠·UI. 이전 번들에서 추출한 JavaScript 이력을 유지합니다. 원본 TypeScript 복구로 주장하지 않습니다.
- `src/research.js`, `src/research-ui.js`: 복제·실측·그래프·연구 노트·자동화.
- `src/persistence.js`: v4 정본·명시적 이전·충돌·복구.
- `assets/manifest.json`, `src/assets.js`, `tools/assets.cjs`: 빈 선택 에셋 계약과 오프라인 빌드 어댑터.
- `origin-lab-v0.2.html`: 변경하지 않은 v0.2 회귀 기준선.
- `tests/v02-*`: 동결된 기준선 테스트. 나머지 테스트는 v0.3 및 이전 동작 회귀.
- [설계](docs/V03-DESIGN.md), [에셋 계약](docs/ASSET-INTEGRATION.md), [QA 보고서](qa/V03-REPORT.md).

실측 JSON과 전체 화면 캡처는 테스트로 `qa/` 아래 생성되며 공개 Git에는 기본적으로 포함하지 않습니다. 전달 ZIP에는 검토한 QA 증거를 포함합니다. `?debug=1`은 테스트용이며 일반 플레이에는 필요하지 않습니다.

코드 라이선스는 미결정입니다. LICENSE·제3자 폰트·새 아트는 추가하지 않았습니다. 이 브랜치는 Draft 검토용이며 배포나 main 병합을 수행하지 않습니다.
