GitHub CI는 일반 Chromium을 설치해 같은 명령을 실행합니다. G1의 최초 실패는 파일 테스트가 PC 기본 뷰포트에서 숨겨진 모바일 탭을 클릭한 테스트 오류였습니다. 명시적 모바일 뷰포트로 수정한 G1 CI는 PASS입니다. 각 Draft PR의 최종 head와 CI 결과는 제출 요약 및 해당 PR Checks에서 확인합니다.

## 실험 해석과 과학적 범위

A/A 일치는 구현의 재현성을 확인하며 실제 세계의 생물학적 정확성을 보증하지 않습니다. 산소·영양분은 모형 상대량, 개체 수는 연속량입니다. 분해 환원은 재고 상한 적용 전 총 환원량이며 마지막 영양분과 다를 수 있습니다. 은신처는 초기에 포식을 줄여도 이후 먹이망이 바뀌어 누적 손실이 다시 늘 수 있습니다. 따라서 UI는 실제 A/B 값을 제시하고 어느 쪽이 언제나 우월하다고 단정하지 않습니다.

첫 장의 기원 설명, 최종 실험, 두 번째 장의 다세포·조간대 설명과 기존 생물 상호작용을 유지했습니다. 이번에는 새 발견이나 보상 ID를 추가하지 않았습니다. 상세 계수와 설계는 [V03-DESIGN](../docs/V03-DESIGN.md), 아트팀 연결 규격은 [ASSET-INTEGRATION](../docs/ASSET-INTEGRATION.md)에 있습니다.

## 미검증·남은 작업

- **UNKNOWN:** 실제 사람이 처음 접했을 때 A/B의 의미를 이해하는지, 초반 클릭·대기 체감, 재실험 동기.
- **UNKNOWN:** 실제 휴대폰, iOS Safari/Android 실기기, Firefox/WebKit, 스크린리더 실제 사용.
- **BLOCKED (로컬):** 관리형 Chromium에서 file:// 직접 열기.
- **별도 에셋 트랙:** 모든 신규 아트·폰트·로고 미제공. 빈 슬롯과 어댑터만 완료. 실제 아트의 선명도·모바일 식별성은 납품 후 검수.
- 저장은 브라우저 로컬 저장과 복구 이력입니다. 다른 주소·기기 간 자동 동기화는 없습니다.
- 자동화 목표는 알려진 경로에서 달성했으나, 사람이 모든 조합을 알아내는 전체 플레이 시간을 측정하지 않았습니다.

실제 플레이에서는 분해자 실험을 처음 발견하는 경로, 표본 준비 전후 차이 이해, 은신처 결과의 간접 효과 해석, 노트 삭제·재실험 흐름을 우선 확인해야 합니다.

## 증거와 공개 범위

전체 전달 ZIP에는 재현 소스, 테스트, 문서, `qa/ab-*.json`, `qa/ui-*.json`, `qa/balance-v03.json`, 브라우저 결과, 화면 캡처를 포함합니다. 데이터는 테스트용 합성 상태입니다. 사용자 플레이 저장이나 계정 정보를 사용하지 않았습니다. 공개 Git에는 실행 소스·검토 문서·테스트 및 선택한 게임 화면만 포함하고 원본 지시서·개인 경로·원본 저장 JSON·실행 로그·캐시·ZIP은 제외합니다.

자동 테스트와 에이전트의 코드/화면 검토를 사람 직접 플레이와 구분합니다. main 병합, Draft 해제, 외부 배포, 저장소 라이선스 추가는 수행하지 않습니다.
