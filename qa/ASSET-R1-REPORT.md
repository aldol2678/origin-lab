## 실제 변경

- 20px 발견·상태·탭 SVG의 밝은/어두운 변형과 18px 생물 PNG, 선택된 생물 SVG를 연결했습니다. 제공된 정본을 임의로 그리거나 수정하지 않았습니다.
- 미발견 32개 도감에는 하나의 중립 잠금 SVG만 사용합니다. 해금된 그림이 선택·테마·로딩 순서 때문에 노출되지 않게 했습니다. 보류 10개는 기존 표시를 유지합니다.
- 기존 `[data-tab]` 선택자가 body까지 선택하는 문제를 버튼 범위로 수정했습니다. 실제 탭 이미지가 해독된 뒤에만 기존 SVG를 숨겨 중복 표시를 제거했습니다.
- 이미지 디코딩 오류는 기본 표시로 돌아가며 실패 URI를 다시 요청하거나 경고를 무한 반복하지 않습니다. 이미지가 없어도 조합과 생태계 플레이가 가능합니다.
- 테마 쿼리를 재사용하고 변경된 패널에 한해 DOM 표시를 적용합니다. 비동기 로딩 완료 시 Canvas를 다시 그려 정지·동작 감소 설정에서도 그림이 반영됩니다.
- 출처 조건에 따른 재선별 도구, 파일·매니페스트 해시 검증, 5개 단위 검사, 8개 브라우저 시나리오를 추가했습니다.

`src/game.js`, `src/chapter.js`, `src/persistence.js`, `src/research.js`, `src/research-ui.js`, `data/catalog.json`은 기준선과 바이트 단위로 같습니다. 저장 키·스키마 변경이나 신규 이전은 없습니다. 기존 v1/v2/v3→v4 이전·충돌·복구 테스트를 다시 실행했습니다.

## 화면 검토와 UNKNOWN

자동 브라우저로 실제 버튼과 Canvas를 조작하고 캡처를 직접 열어 모바일 실험실, PC 어두운 세계 화면의 아이콘 크기·배치·중복 표시·대비를 시각적으로 검토했습니다. 이는 사람이 게임을 처음부터 끝까지 직접 플레이한 것과 구분합니다.

- 로컬 `file://` 2개 검사는 관리 정책이 파일 로드를 차단하여 BLOCKED입니다. 정책을 우회하지 않았습니다. 네트워크 차단 라우팅 페이지에서 독립 HTML 실행은 PASS입니다.
- 실제 휴대폰·Safari·Firefox·고배율 장시간 플레이: **UNKNOWN**.
- 처음 보는 사람이 18/20px에서 9종을 알아보는 정도, 색각 다양성, 스크린 리더 직접 사용: **UNKNOWN**.
- 사람 직접 전체 플레이·장시간 배터리/메모리 측정: **UNKNOWN**.
- 누락 명세 조항별 준수 및 보류 10개 그림의 원본 공개 권리: **BLOCKED**.

설계자 확인 시 9종의 작은 실루엣과 선택 표시, 밝은/어두운 화면의 가독성, 보류 10개의 기존 표시와 새 아이콘의 혼합이 플레이를 방해하는지 확인하는 것이 좋습니다. 보류 그림의 출처와 공개 권한이 확인되면 별도 연결 검토가 가능합니다.
